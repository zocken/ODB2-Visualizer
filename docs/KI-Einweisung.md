## Inhalte

| Thema | Inhalt | Erledigt |
|---|---|---|
| Modellfehler | Sprachmodelle können plausibel klingende, aber falsche Angaben erzeugen (erfundene Messwerte, Herstellerangaben, Quellen); Denkmodelle brauchen lange und können ins Token-Limit laufen | ☐ |
| Quellenprüfung | Unterschied redaktionelle vs. automatisch importierte Einträge (Wal33D, automatisch übersetzt, Dringlichkeit ungeprüft); Quellenhinweise bestätigen nicht die ganze Antwort | ☐ |
| Fahrzeugrisiken | Sicherheitssysteme (Bremsen, Lenkung, Öldruck, Überhitzung, Airbag, Hochvolt); keine Freigabe zur Weiterfahrt; Sofort-Hinweise und [Prüfliste Sicherheitstexte](Pruefliste-Sicherheitstexte.md) | ☐ |
| Datenschutz | Was verarbeitet wird, was nicht gespeichert wird; keine personenbezogenen Daten in Tests oder KI-Werkzeuge; [Betriebsprüfung](KI-Betriebspruefung.md) | ☐ |
| Sicherheitsvorfälle | [Vorfallablauf](KI-Vorfallablauf.md), Abschalter `CHAT_DISABLED`, Sperren und Korrigieren von Codes | ☐ |
| KI als Entwicklungswerkzeug | Ergebnisse vor Übernahme prüfen; keine Zugangsdaten in KI-Eingaben; Simulationen als solche kennzeichnen (Abschnitt 12) | ☐ |
| Prüfungen | Simulierte Tests (`npm test`) vs. Tests mit dem echten Modell; nur Durchgeführtes dokumentieren ([Umsetzungsstand](KI-Umsetzungsstand.md)) | ☐ |
